# v0.25 integral ecosystem position

v0.25 strengthens the operational plane while preserving the complete KWAN
envelope.

| Plane | Components | v0.25 contribution |
|---|---|---|
| Formal-semantic | KwanCode, CSI | Mission and request identities remain typed |
| Constitutional | KCH | Exact coordination and component leases remain separate |
| Operational | KwanTau DOS, Ride | Durable runs, work queues and rehydration |
| Personal sovereignty | KwanMe | Encrypted artifact and encrypted human rationale |
| Knowledge/evidence | KwanDocs, KwanBlocks | Causal effect evidence and immutable receipts |
| Personal intelligence | Onboarding Learning, Jarvis | Suggestions and candidate learning without authority |
| World model | Country World | Consequences and jurisdiction relations in authority requests |
| Experimental | Sweetbox, CreaLabs | SHADOW execution and preregistered comparisons remain separate |
| Surfaces | Kwan Browser, Telegram container | Human visibility without ambient effect authority |
| Host/exchange | Device Fabric, Host Lanes, Truqueplace | Future worker and package embodiments |
| Recovery | Missing-Intent Recovery | Unresolved intent remains unknown |

The runtime now exposes twenty-eight services. This does not create a twentieth
mandatory architectural component: `MISSION_RUNTIME` is the durable service
that operationalises the already mandatory KwanTau DOS, Ride, KCH and mission
planes.

## Non-equivalences

```text
more scheduler state ≠ more authority
human approval ≠ productive lease
effect binding ≠ effect execution
mission completion ≠ whole-system completion
successful fixture ≠ real-world utility
```
