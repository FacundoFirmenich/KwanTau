**Status:** executable SHADOW alpha

**Canon:** `No run. No implant. Ride.`  
**Authority inherited:** false  
**Automatic promotion:** blocked

## Abstract

This release reconciles two previously separate research lines without claiming a false source-code merge:

1. the constitutional and jurisdictional line through KCH, KwanMe, Country World, benchmark federation and calibrated external effects;
2. the external prospective line that specified a future-only four-arm campaign for distinguishing base capability, approved memory, learned skills and the full personal candidate.

The external v0.22 source bytes are not available in this tree. Its RFCs and sealed release receipt are preserved by hash as scientific lineage; their semantic invariants are reimplemented and tested on the current canonical tree. Presence of an RFC or receipt never implies source-code import, Git ancestry or authority.

## Integral composition

```text
Ride and first-inflation freeze
→ KwanMe personal snapshots
→ four frozen arm contexts
→ future trigger and user-approved case
→ same-provider sealed outputs
→ blinded review and later outcome evidence
→ unblinding and leakage audit
→ counterfactual KCH policy audit
→ local Bayesian attribution by season and stratum
→ KwanBlocks zero-authority receipt
```

The four arms are:

```text
BASE
MEMORY
MEMORY_SKILL
FULL_PERSONAL
```

Their ordered contrasts are:

```text
MEMORY   = MEMORY - BASE
SKILL    = MEMORY_SKILL - MEMORY
PERSONAL = FULL_PERSONAL - MEMORY_SKILL
TOTAL    = FULL_PERSONAL - BASE
```

This ordered decomposition is not Shapley attribution and does not identify every interaction.

## Future-only invariant

The campaign is frozen before any case is admitted. Freeze seals:

- Ride identity;
- foundation/provider/model identities;
- first-inflation, memory, skill and personal-candidate snapshots;
- seasons;
- trigger families;
- local jurisdictions, segments, queue classes and edges;
- evidence and reviewer-independence requirements;
- Bayesian thresholds;
- authority-safety guardrails;
- evaluation-to-training exclusion.

The temporal ordering is:

```text
freeze < event < admission < four outputs < blind review < outcomes < unblind < audit < analysis
```

A real future case requires explicit user approval. Software fixtures are permitted only for protocol testing and are never pooled with empirical cases.

## Personal-data boundary

Task and output plaintext remain in KwanMe. The main database stores descriptors, hashes, blind labels and genealogy only. Evaluation objects are permanently marked `training_eligible=false`.

```text
memory access          ≠ training
review score           ≠ training signal
outcome evidence       ≠ training signal
campaign support       ≠ personal-state promotion
```

## Counterfactual authority audit

Each arm may emit an authority proposal. The audit compares it with a frozen reference decision while asking KCH only for counterfactual policy support. It never calls lease issuance.

Classifications:

```text
MATCH
UNSAFE_EXPANSION
OVER_RESTRICTION
NO_PROPOSAL
DIVERGENT_DENIAL
```

A candidate that improves task utility but expands authority beyond the reference guardrail cannot receive a favourable local verdict.

## Local-first longitudinal analysis

The primary unit is:

```text
season × jurisdiction × segment × queue class × edges × contrast
```

Bayesian bootstrap distributions estimate ordered utility differences. A result can be:

```text
SUPPORTED
ADVERSE
MIXED
INSUFFICIENT
NO_EMPIRICAL_CLAIM
PROTOCOL_FIXTURE_ONLY
```

Global summaries are `ACCESSORY_ONLY`; they cannot override an adverse, mixed or insufficient required local stratum. Season-to-season changes are recorded as `STABLE`, `REGIME_SHIFT` or `INSUFFICIENT`.

## Scientific boundary

At release time there are no real post-freeze cases. The material demo intentionally closes with zero empirical cases and therefore yields:

```text
NO_EMPIRICAL_CLAIM
```

Software fixtures validate mechanics, immutability, blindness, policy-audit safety and statistical code. They do not establish a personal advantage, reviewer independence or model improvement.

## Next empirical gate

The next scientific gate is the first user-approved post-freeze event matching a preregistered trigger, followed by four genuine same-provider outputs, later outcome evidence, blind adjudication, leakage audit and local analysis. No automatic campaign enrollment or passive surveillance is permitted.
