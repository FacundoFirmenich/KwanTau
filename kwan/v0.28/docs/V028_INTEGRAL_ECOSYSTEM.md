# v0.28 integral ecosystem position

v0.28 connects the conversational, experimental and mission planes without narrowing the KWAN envelope.

| Plane | Components | v0.28 contribution |
|---|---|---|
| Formal-semantic | KwanCode, CSI | Opaque source-item identities and typed contracts |
| Constitutional | KCH | Separate leases for campaign, case, plan, review, outcome, analysis and repair |
| Operational | KwanTau DOS, Ride | Durable future-only campaign and successor missions |
| Personal sovereignty | KwanMe | Encrypted task and private context custody |
| Evidence | KwanBlocks | Analysis and repair receipts, authority ceiling `NONE` |
| Personal intelligence | Onboarding Learning, Jarvis | Candidate interpretation without promotion |
| World model | Country World | Jurisdiction remains a local stratum when relevant |
| Experimental | Sweetbox, CreaLabs | Blind comparison and preregistered analysis |
| Surfaces | Kwan Browser, Telegram container | Visibility without productive authority |
| Host/exchange | Device Fabric, Host Lanes, Truqueplace | Future multi-device execution and distribution |
| Recovery | Missing-Intent Recovery, KwanThread Federation | Unknowns and provenance preserved |
| Mission | Integral Mission Fabric, Mission Runtime | Closed-parent / successor-repair causality |

The runtime exposes thirty-four services while preserving all nineteen mandatory components. `PROSPECTIVE_THREAD_UTILITY` and `CAUSAL_MISSION_REPAIR` are services, not replacement components.

## Non-equivalences

```text
context richness ≠ utility
evaluation ≠ training
repair ≠ historical rewrite
analysis receipt ≠ scientific truth
mission successor ≠ inherited authority
```
