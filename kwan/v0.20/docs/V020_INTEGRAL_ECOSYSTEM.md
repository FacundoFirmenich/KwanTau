# v0.20 integral ecosystem position

v0.20 is not a Country World side project. It strengthens one plane while preserving all nineteen mandatory components.

| Plane | Components | v0.20 relation |
|---|---|---|
| Formal-semantic | KwanCode, CSI | Source claims remain typed and genealogical |
| Constitutional | KCH | Exact leases for contracts, ingestion and calibration |
| Operational | KwanTau DOS, Ride | Durable service lifecycle without authority transport |
| Personal sovereignty | KwanMe | Future source credentials remain opaque handles |
| Knowledge/evidence | KwanDocs, KwanBlocks | Documents and immutable source/calibration receipts |
| Personal intelligence | Onboarding Learning, Jarvis | May interpret reports, never self-authorise |
| World model | Country World | Bitemporal evidence plus local-stratum risk gates |
| Experimental | Sweetbox, CreaLabs | Future adapter bake-offs and preregistered calibration matrices |
| Surfaces | Kwan Browser, Telegram container | Visibility and interaction, not authority |
| Host/exchange | Device Fabric, Host Lanes, Truqueplace | Future source execution and signed distribution |
| Recovery | Missing-Intent Recovery | Unknown source meaning remains unresolved |

The runtime has twenty-one registered services because Country World now exposes separate source-adapter and selective-risk services. This does not add new mandatory architectural components or narrow the master map.

## Governing non-equivalences

```text
more source pages ≠ more independent evidence
parser correctness ≠ jurisdiction-level calibration
global mean ≠ local support
coverage ≠ authority
source signature ≠ truth
calibration report ≠ KCH lease
```
